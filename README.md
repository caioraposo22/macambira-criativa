# Macambira Criativa

Site da Macambira Criativa, agência digital do Recife: sites, web apps e tráfego pago, com branding e design.

Site estático, sem etapa de build. A raiz do repositório é a raiz do site.

- `index.html`: página inicial
- `precos.html`: preços e prazos
- `estudo-saude.html`: projeto Gestão APS
- `estudo-serralheria.html`: estudo de tráfego pago
- `robots.txt`, `sitemap.xml`, `llms.txt`: buscadores e assistentes de IA
- `vercel.json`: configuração da hospedagem
